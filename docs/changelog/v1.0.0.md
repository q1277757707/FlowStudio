# v1.0.0 — 第一阶段 MVP

**发布日期**：2026-05-21

## 概述

完成 Vue3 + Element Plus 低代码设计器最小闭环：JSON Schema 驱动、物料拖拽、画布编辑、属性配置。

## 新增

### 工程与模块

- Monorepo 风格 `packages/`：`designer-core`、`designer-materials`、`designer-renderer`、`app-designer`
- Vite + Vue3 + Pinia + Element Plus + vuedraggable 工程脚手架

### designer-core

- `PageSchema` / `LowCodeNode` 类型定义
- `createInitialSchema()` 空画布初始化
- `findNodeById`、`removeNodeById`、`createGridCells` 等节点工具

### designer-materials

- 物料协议：`MaterialMeta`、Setter 类型（String/Number/Select/Boolean/Option/Transfer）
- 内置物料：容器、表单、常见表单控件、按钮、文本

### designer-renderer

- `SchemaRenderer` 递归渲染（编辑态 / 预览态）
- 容器网格 `gridCells`、嵌套 `Draggable` 投放区
- 编辑态字段 `readonly`，基础选中样式

### app-designer

- 三栏布局：物料区 | 画布 | 右侧属性/事件/变量/日志
- 顶部预览弹窗、清空画布
- 属性面板界面化配置 props
- Schema 复制预览

## 物料清单（v1.0.0）

- 布局：容器（纵向 / 网格）
- 表单：表单容器
- 表单字段：输入框、多行文本、数字、下拉、单选、多选、开关、日期、时间、滑块、评分、颜色、级联、树选择、穿梭框、上传
- 基础：按钮、文本

## 已知限制

- 无变量表达式、无完整事件动作链执行
- 无撤销重做
- 无 `designer-sandbox` 模块
- 无拖拽投放区类型限制
- 预览与编辑视觉样式未区分
