# v1.1.0 — 渲染拆分、校验、沙箱与拖拽体验

**发布日期**：2026-05-21  
**基于**：v1.0.0

## 概述

在 MVP 基础上完善渲染架构、表单能力、安全执行与拖拽规则，并优化编辑/预览体验。

---

## 新增

### 模块

| 模块/路径 | 说明 |
| --- | --- |
| `packages/designer-sandbox` | Proxy + `with` 沙箱，表达式 / customJS 执行 |
| `packages/designer-core/src/validation.ts` | 表单校验规则构建（必填、格式、长度） |
| `packages/designer-materials/src/dragRules.ts` | 拖拽投放区规则与 `createDragGroup` |
| `packages/designer-renderer/src/components/fields/` | 按控件拆分的 Field 组件与注册表 |
| `packages/designer-renderer/src/composables/` | `useFieldBinding`、`useFieldValidation`、`useTextLengthLimit`、`useDragMove`、`useDesignerDragFeedback` |

### 渲染器架构拆分

- `SchemaRenderer.vue`：薄入口，仅 `provideRendererRuntime` + `RendererList`
- `RendererList` / `RendererNode`：列表与节点分发
- `ContainerRenderer` / `FormRenderer`：容器与表单
- `FieldRenderer` + `fields/index.ts`：`type → 组件` 注册，支持 `registerFieldRenderer` 扩展

### 表单校验（属性面板可配）

所有表单类物料增加：

| 属性 | 说明 |
| --- | --- |
| `required` | 必填 |
| `validateType` | 无 / 邮箱 / 手机 / 网址 / 身份证 / 数字 / 整数 / 仅中文 / 仅英文 / 自定义正则 |
| `customPattern` | 自定义正则（仅 `validateType=custom` 时显示） |

输入框、多行文本额外支持：

| 属性 | 说明 |
| --- | --- |
| `minLength` | 最少字符（0 表示不限制） |
| `maxLength` | 最多字符（0 表示不限制，启用字数统计） |

- 统一由 `FieldFormItem` + `buildFieldRules` 在**预览态**触发 Element Plus 校验
- `FormRenderer` 预览时绑定 `formModel`

### 沙箱（designer-sandbox）

- `createScopeProxy`：`has` 拦截，防止 `with` 作用域泄漏
- `runExpression` / `runScript` / `evaluateTemplate`
- 预览按钮 `click` 动作链：`message`、`customJS`（scope 注入 `form`、`message`）
- **注意**：`with` 与 strict 模式不兼容，沙箱函数体不使用 `"use strict"`

### 拖拽投放规则

| 投放区 | 允许 | 禁止 |
| --- | --- | --- |
| 画布 / 容器 | 表单、容器、按钮、文本 | 表单字段（输入框、下拉等） |
| 表单内 | 表单字段、容器、按钮、文本 | 嵌套表单 |

- `group.put` + `move` 双重校验
- 从 `dragEl._underlying_vm_`、`data-component-type` 解析组件类型
- **非法投放光标**：`not-allowed`，合法为默认/抓取；`dropEffect: none`

### 预览与编辑样式

- **编辑态**：保留容器/表单/网格虚线边框与选中高亮（`is-edit-mode` 不隐藏边框）
- **预览态**：`is-preview-mode` 隐藏设计边框，接近真实页面

### 预览交互

- `runtimeValues` + `useFieldBinding`：预览可输入、选择
- 按钮可执行已配置事件动作链

## 变更

- 右侧属性面板：校验格式选「自定义正则」时才显示「自定义正则」输入框
- 物料区、画布空状态文案：说明须先拖入表单再放表单组件
- 设计文档第十章：区分 Proxy+with 沙箱与 iframe 远程物料沙箱

---

## 移除

- 物料 **穿梭框（Transfer）** 及 `TransferField`、相关运行时 `readTransferData`

---

## 修复

- 跨列表拖拽时 `draggedContext.element` 不可靠 → 改用 `_underlying_vm_` 与 DOM `data-component-type`
- 仅依赖 `move` 导致投放判断不准 → 增加 `createDragGroup` 的 `put` 函数
- 非法投放仍显示「移动」光标 → `useDesignerDragFeedback` + 全局样式
