# v1.2.0 — 事件系统

## 新增

### packages/designer-event

- `ActionRegistry` 插件注册表
- `ActionRunner` 顺序执行、日志、可配置 `continueOnError`
- `EventDispatcher` 事件调度与 payload 合并
- 内置 Action：`request`、`setVariable`、`setFormValue`、`message`、`dialog`、`navigate`、`reload`、`emit`、`condition`、`loop`、`delay`、`customJS`、`setVisible`
- `ExpressionResolver`：`{{ }}` 模板与配置项解析
- `httpRequest`（axios）统一 HTTP
- `applyFormAssignments`：请求成功 / 组件赋值；`assignments` 在请求完成后再解析 `lastResponse`
- 对外 API：`runEventActions`、`globalEventDispatcher`

### 设计器

- 底部 `EventPanel`：触发事件、动作链、**可视化动作配置**（`NestedActionConfigForm`、`RequestConfigForm`、`SetVariableConfigForm`、`SetFormValueConfigForm`）
- `ConditionBranchEditor`：条件表达式 + true/false 子动作
- `FormAssignmentEditor`：请求成功后赋值 / 组件赋值
- `designer` store：`addEventAction`、`updateEventConfig`、撤销重做
- Schema：`EventAction.id`、`pageEvents`、`setFormValue` 动作类型

### 渲染器

- `useFieldEvents`：画布与预览均触发 `change` / `input` 等（`setVisible` 仍仅预览）
- `useRendererRuntime`：`setFormFieldValue`、动态选项覆盖、`eventLogs`
- 赋 `{ label, value }[]` 更新 Select 等选项；赋 `[]` 清空选项与选中值
- 预览 `pageEvents.pageLoad`（`schema.pageEvents`）

### 物料与 Mock

- 选项类组件 **数据来源**：静态 / 接口（`/api/options/list`、`/api/options/tree`）
- `viteApiMockPlugin`：`/api/demo`、`/api/options/*`
