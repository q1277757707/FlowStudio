# v1.2.0 — 事件系统

## 新增

### packages/designer-event

- `ActionRegistry` 插件注册表
- `ActionRunner` 顺序执行、日志、可配置 `continueOnError`
- `EventDispatcher` 事件调度与 payload 合并
- 内置 Action：`request`、`setVariable`、`message`、`dialog`、`navigate`、`reload`、`emit`、`condition`、`loop`、`delay`、`customJS`
- `ExpressionResolver`：`{{ }}` 模板与配置项解析
- 对外 API：`runEventActions`、`globalEventDispatcher`

### 设计器

- 底部 `EventPanel`：选择触发事件、添加/删除动作、JSON 编辑 config
- `designer` store：`addEventAction`、`removeEventAction`、`updateEventConfig` 等
- Schema 扩展：`EventAction.id`、`pageEvents`、更多 `EventActionType`

### 渲染器

- `useFieldEvents`：预览态 `change` / `input` / `blur` / `focus`
- `useRendererRuntime`：统一 `RuntimeContext`、API、弹窗、日志
- 预览 `pageLoad` 支持（`schema.pageEvents`）

### 文档

- [docs/event-system.md](../event-system.md) 完整事件系统设计说明

## 变更

- `packages/designer-renderer/src/utils/runEventActions.ts` 改为转发 `@designer-event`
- 原内联 switch 执行逻辑已移除
