# v1.2.1 — 流程设计模块拆分

## 变更

### packages/designer-workflow（新包）

- 自 `app-designer` 迁出流程设计相关代码，包名 `@flow-studio/designer-workflow`
- 包含：`workflow-canvas/` 画布、`Workflow*` 组件与抽屉、`useWorkflowStore`、流程专用样式
- 通过 `pageMetaBridge` / `formFieldsBridge` 由宿主注入页面元信息与表单字段，避免依赖表单设计 store

### packages/app-designer

- `DesignerShell` 改为从 `@designer-workflow` 引入 `WorkflowDesignerPanel` 与 store
- 新增 `workflow/collectFormFields.ts`，供条件分支读取表单组件 ID
- 移除已迁移的 `workflow-canvas/`、`store/workflow.ts`、流程组件目录

### 工程配置

- `vite.config.ts`、`tsconfig.json` 增加别名 `@designer-workflow`
- `src/main.ts` 改为 `import '@designer-workflow'` 统一加载流程样式
- `src/styles.css` 中流程相关样式迁入 `designer-workflow/src/styles/`

### 文档

- 新增 [workflow-design.md](../workflow-design.md)
- 更新 [lowcode-design.md](../lowcode-design.md) 架构表

## 说明

- **无 UI 变更**：拆分前后流程设计步骤的界面与交互保持一致
- `designer-core/workflow.ts` 仍负责模板类型与 `compileWorkflowTemplate`，未移动
- 画布实现目录由 `flow-beeflow` 重命名为 `workflow-canvas`，类型与组件前缀统一为 `Workflow*`（如 `WorkflowNode`、`WorkflowCanvas`）
