# FlowStudio

一个用于构建企业工作流、事件编排与动态应用的可视化低代码平台。

## 技术栈

- Vue 3 + Element Plus + Pinia + Vite
- JSON Schema 驱动页面与事件配置
- `packages/designer-event` 事件动作链引擎

## 快速开始

```bash
npm install
npm run dev
```
